### Projetos em destaque

####  Profit Brain Delivery
Sistema de gestão para dark kitchen que cobre o fluxo do delivery, do cardápio à entrega.

- Controle de acesso com 4 perfis: gerente, cozinha, motoboy e cliente
- Dashboard gerencial com KPIs em tempo real e cadastro completo de produtos
- Kanban da cozinha, painel de entregas e rastreamento de pedidos

**Tecnologias:** HTML5 · CSS3 · JavaScript · Firebase/Firestore

 [Acessar o projeto](https://profit-brain.web.app) · [Ver o repositório](https://github.com/jpcremm/profit-brain-delivery)

####  Controle de Impressora Térmica Elgin (i8/i9)
Aplicação de terminal em C que controla a impressora pela DLL oficial da Elgin. Trabalho acadêmico em trio, feito a partir de um programa-base do professor.

- Impressão de texto, QR Code, código de barras e cupons SAT (venda e cancelamento)
- Acionamento de gaveta e sinal sonoro
- Login com limite de tentativas e tratamento de erros
- Todo o código funcionou na validação em impressora física

**Tecnologias:** C · Windows API · SDK Elgin

 [Ver o repositório](https://github.com/jpcremm/impressora-elgin-c)
